## Skills

`MATLAB` · `matrix filters` · `HSV` · `denoising`

## The problem

Raw sensor frames are noisy and hard to read as numbers in a table. The goal
was a pipeline that cleans the signal and makes magnitude obvious visually —
a heatmap a human can skim, not a spreadsheet of intensities.

## Approach

**Write the filters.** Custom matrix filters ingest and denoise the frames as
explicit matrix operations so every coefficient is inspectable in the script.
No `imgaussfilt`-style black box for the core path — the point of the exercise
was seeing the linear algebra.

**Colour as magnitude.** After cleanup, intensity maps into HSV space so hue /
value carry the story. Hot spots should pop without reading every cell.

**Pipeline.**

```
raw frame  →  denoise kernel  →  normalize  →  HSV heatmap
```
