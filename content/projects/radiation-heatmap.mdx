## Problem and outcome

Raw frames are hard to read as tables. I built a small MATLAB pipeline that
denoises with custom kernels and renders magnitude as an HSV heatmap.

## Role

Solo course exercise.

## Approach

```
raw frame  →  denoise kernel  →  normalize  →  HSV heatmap
```

Filters are written as matrix operations so coefficients stay inspectable.

## Limitations

Cover art is a conceptual diagram. A real MATLAB export can replace it if the
dataset is shareable. This is not a fielded radiation instrument.
